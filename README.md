# URLpipe Homebrew tap

```sh
brew install urlpipe/tap/urlpipe
```

`urlpipe` turns any URL into Markdown, rendered HTML, a screenshot, metadata, console errors or a Lighthouse audit, from the terminal. Pages are rendered in real Chrome.

The cask here is written by the release workflow of [URLpipe/urlpipe-go](https://github.com/URLpipe/urlpipe-go); don't edit it by hand. Docs: https://urlpipe.dev/docs/client-libraries
